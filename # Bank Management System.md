# Bank Management System

## Project Overview

The **Bank Management System** is a simple console-based Python project developed to perform basic banking operations.

The system allows users to create bank accounts and perform operations such as depositing money, withdrawing money, checking balance, transferring money, viewing account details, and closing accounts.

## Features

* Create a new bank account
* Display account details
* Deposit money
* Withdraw money
* Check account balance
* Transfer money between accounts
* Close an account
* Display all available accounts
* Exit the system

## Technologies Used

* **Programming Language:** Python
* **Interface:** Console / Command Line
* **Storage:** Python Dictionary

## How to Run

1. Install Python 3 on your computer.
2. Download or clone this project.
3. Open the project folder in a terminal.
4. Run the following command:

```bash
python bank_management_system.py
```

5. Follow the options displayed in the menu.

## Important Note

This project is created for educational purposes. Account information is stored temporarily in memory using a Python dictionary. The data will be lost when the program is closed.
