# Problem Statement

## Bank Management System

Banks need to maintain and manage customer account information and provide basic banking services such as deposits, withdrawals, balance checking, and money transfers.

The objective of this project is to develop a simple **Bank Management System using Python** that can perform these basic operations through a console-based interface.

The system should allow a user to:

1. Create a new bank account.
2. Store basic customer information such as name and phone number.
3. Generate a unique account number.
4. Deposit money into an account.
5. Withdraw money from an account.
6. Check the current account balance.
7. Transfer money from one account to another.
8. Display individual account details.
9. Display all available accounts.
10. Close an existing bank account.

The project uses Python dictionaries to temporarily store account information and functions to organize different banking operations.

## Objective

The main objective of this project is to demonstrate how fundamental Python programming concepts can be combined to create a practical, menu-driven application.

## Scope

This project is designed as a basic educational banking application. It does not use a real database, online banking system, or external payment gateway.

The account information remains available only while the Python program is running.

## Expected Outcome

After completing the project, the user should be able to perform basic banking operations through a simple and easy-to-use console interface while understanding the practical implementation of Python programming concepts.
